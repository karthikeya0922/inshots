# Examples

`signalgrid/` is the complete text output of one real run against `test/fixtures/vite-react-saas`
(a Vite + React + Recharts anomaly-detection dashboard):

```
frameo test/fixtures/vite-react-saas --quality looks
```

Read `launch-plan.md` (the creative north star), `storyboard.md` (the scene contract),
`composition-brief.md` (the Hyperframes handoff), `product-dna.json` (the source of truth),
`claim-verification.json` (what was verified and what was deliberately kept out — note the
README's "Trusted by 500+ engineering teams" and "99.99% detection accuracy" are excluded), the
`share-copy/` variants, and `poster.png` (the hero frame, also baked as frame 0 of the video).

The MP4 itself is not committed; render it with the command above (≈2 minutes on a laptop).
